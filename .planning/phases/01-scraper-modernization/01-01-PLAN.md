<task type="auto">
  <name>Task 1: Initialize uv project and pin Python 3.13</name>
  <files>pyproject.toml, .python-version</files>
  <action>
Run from the project root (`/Users/jan.prill/codex/gesetze-im-internet`):

```bash
uv init --no-package
uv python pin 3.13
```

`uv init --no-package` is mandatory — the `--no-package` flag prevents uv from creating a `src/` layout and `__init__.py`. Without it, `uv run scrape.py` may fail with import errors.

After running, verify the generated `pyproject.toml` has `requires-python = ">=3.13"` and does NOT contain a `[build-system]` block. If `uv init` created a `main.py`, delete it — this project has no `main.py`.

The `pyproject.toml` must include a `[tool.pytest.ini_options]` section for the test framework used in Plan 02:

```toml
[tool.pytest.ini_options]
testpaths = ["tests"]
```

Add this section to `pyproject.toml` after the `[project]` block. The full target shape of `pyproject.toml`:

```toml
[project]
name = "gesetze-im-internet"
version = "0.1.0"
requires-python = ">=3.13"
dependencies = [
    "beautifulsoup4>=4.12",
    "lxml>=5.0",
    "requests>=2.31",
]

[dependency-groups]
dev = [
    "pytest>=8.0",
    "pytest-mock>=3.12",
]

[tool.pytest.ini_options]
testpaths = ["tests"]
```

Note: uv generates some fields automatically. Edit the file to match the target shape after `uv init` runs.
  </action>
  <verify>
    <automated>cd /Users/jan.prill/codex/gesetze-im-internet && grep -q 'requires-python = ">=3.13"' pyproject.toml && cat .python-version</automated>
  </verify>
  <done>`pyproject.toml` exists with `requires-python = ">=3.13"`, `.python-version` contains `3.13`, no `[build-system]` block, no `main.py` created.</done>

<task type="auto">
  <name>Task 2: Add runtime and dev dependencies, generate uv.lock, retire old files</name>
  <files>pyproject.toml, uv.lock, requirements.txt, requirements_dev.txt</files>
  <action>
Run from project root:

```bash
cd /Users/jan.prill/codex/gesetze-im-internet
uv add "requests>=2.31" "beautifulsoup4>=4.12" "lxml>=5.0"
uv add --dev "pytest>=8.0" "pytest-mock>=3.12"
```

These commands update `pyproject.toml` dependencies and generate `uv.lock`. The `lxml>=5.0` lower bound is required — lxml <5.0 has no binary wheels for Python 3.13 and causes CI to attempt a C source compilation, which will fail on a bare runner.

After `uv add` completes, verify `uv.lock` exists and is non-empty.

Then delete the old dependency files:

```bash
git rm requirements.txt requirements_dev.txt
```

If `requirements_dev.txt` does not exist as a tracked git file, use `rm` instead of `git rm` for that file. Both files must be absent after this step — they are superseded by `pyproject.toml` + `uv.lock`.

Finally, verify the full install works:

```bash
uv sync --frozen
```

This installs exactly what `uv.lock` specifies. It must complete without "Building lxml..." output (which would indicate missing wheels). If lxml compiles from source, the `>=5.0` constraint is not taking effect — check the `uv.lock` file for the resolved lxml version.
  </action>
  <verify>
    <automated>cd /Users/jan.prill/codex/gesetze-im-internet && uv sync --frozen && echo "sync OK" && test ! -f requirements.txt && echo "requirements.txt gone"</automated>
  </verify>
  <done>`uv sync --frozen` exits 0 without compiling lxml from source. `uv.lock` is committed. `requirements.txt` and `requirements_dev.txt` are deleted.</done>
</task>
